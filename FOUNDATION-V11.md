# AB Photography — Foundation V11

Esta versión consolida la base pública del sitio.

## Cambios
- CSS reconstruido en una sola hoja coherente, sin bloques V7/V8/V9/V10 que se sobrescribían.
- Diseño responsive consolidado para escritorio, tablet y móvil.
- Lightbox cerrado por defecto y abierto únicamente al seleccionar una fotografía.
- Navegación del lightbox mediante botones, teclado y swipe.
- Restauración de la posición de scroll al cerrar la galería.
- JavaScript defensivo para evitar errores cuando un elemento no está presente.
- Menú móvil con estado `aria-expanded` y diálogo de galería con atributos accesibles.
- Se conservaron el contenido bilingüe, el formulario de WhatsApp y las páginas administrativas.

## Archivos principales modificados
- `styles.css`
- `script.js`
- `index.html`

`styles.pre-v11.css` conserva temporalmente la hoja anterior como referencia. Puede eliminarse después de aprobar la V11.
