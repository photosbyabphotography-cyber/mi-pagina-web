# SESIONES POR CATEGORÍA

Se agregó una portada de Sesiones con tres colecciones:
- Parejas (`sessions-couples`)
- Graduación (`sessions-graduation`)
- Embarazo (`sessions-maternity`)

El Portfolio Manager incluye las tres categorías nuevas. La opción `Sesiones · Archivo actual` conserva acceso a las fotografías que ya estaban guardadas con la categoría antigua `sessions`; no se borró ni migró ninguna foto existente.

Las portadas de las tres tarjetas se actualizan automáticamente desde Supabase cuando marcas una foto como portada en cada categoría.

- Familiar → `sessions-family` → `familiar.html`
