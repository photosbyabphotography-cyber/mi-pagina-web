# Visibilidad de categorías

Las subcategorías de Sesiones y Eventos se ocultan automáticamente en la web pública cuando no tienen fotografías visibles.

En Portfolio Manager aparece un panel **Mostrar u ocultar secciones**:
- Si una categoría tiene fotos, el interruptor permite ocultar o mostrar todas sus fotos.
- Si no tiene fotos, aparece deshabilitada y la tarjeta pública queda oculta automáticamente.
- Las fotografías no se borran al ocultar una sección.

Esto permite mantener, por ejemplo, Bridal Shower configurado en el sistema aunque todavía no tenga fotografías.
